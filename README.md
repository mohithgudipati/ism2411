#2. How Git will change how I edit scripts

In modules previous to this one we would edit a working script directly and make sure we did not change anything other then one line. With git however we can make small changes and check it with the git status command and only commit the change once we check that it works. It also allows us to have a saved version of code to always go back to if results are unsatisfactory. I have also learned through this module to check a file before commiting because my first copy of funtions.py was blank and I saw it before I saved it.
